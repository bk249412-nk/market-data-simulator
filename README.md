Market Data Simulator

A C++17 project that simulates stock prices and performs basic market analytics.

Features

- Simulates price movements for AAPL, MSFT, and TSLA.
- Calculates the five-period moving average (MA-5).
- Displays percentage price changes.
- Generates price alerts when the absolute price change reaches 1% or more.

Technologies

- C++17
- Standard C++ Library
- Git and GitHub

How to Compile and Run

Compile the program:

clang++ -std=c++17 src/main.cpp -o market-simulator

Run it:

./market-simulator

Purpose

This project demonstrates basic C++ programming, financial data simulation, moving-average calculations, and price-alert logic.
